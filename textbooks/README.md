# 各学科教材

本目录保存个人教材工程的现有成品和编写、构建文件，上传日期为 2026-10-19。教材版本与更新情况以 `outputs/教材清单.json`、`outputs/更新日志.md` 为准；此次仅备份，没有重新构建或改写教材。

- [教材总目录](outputs/教材总目录.md)
- [PDF 合集](outputs/各学科教材合集.pdf)
- [完整教材下载包](outputs/各学科教材_分册与源文件.zip)
- [各科 PDF、Markdown 与离线 HTML](outputs/教材/)
- [内容增补核对记录](outputs/内容增补核对记录.md)
- [来源覆盖与编写说明](outputs/来源覆盖与编写说明.md)

`work/` 保存构建、修订脚本、教材维护规则及覆盖核验数据。`skills/` 保存原工程使用的课程编写技能。脚本沿用原工程环境与路径，部分脚本是一次性迁移工具，请先阅读 `work/教材维护规则.md`，不要批量运行。依赖、原始来源和自动化会话状态没有打包，因此这里不承诺能够直接从零重建。

原始聊天记录、私人附件、第三方参考书扫描页、临时渲染缓存和历史备份未上传。来源材料访问缺口沿用现有说明。旧维护规则中的“不上传”针对当时的日常自动维护；本次上传依据用户在当前聊天中的明确要求，不改变后续自动维护行为。

`SHA256SUMS.json` 记录本目录上传文件的路径、大小与 SHA-256，可用于完整性核对。
