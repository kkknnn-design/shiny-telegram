# 手写体识别（Handwriting Reader）

用户是学俄语的中国学生，常发来方格本上的俄语手写作业照片。目标：**准确转写 → 翻译 → 指出错误**，而不是只给一段文字。

## 工作流程

1. **先看整体结构**：题号、句数、是否有统一句型（如 «Чем…, тем…»、变格练习、填空）。句型能反过来帮你确认难认的词。
2. **看不清就放大**：用 Python + Pillow 裁剪/放大局部再看（`img.crop(box).resize((w*2,h*2))`），不要猜。逐行裁剪比整图更可靠。
3. **逐词转写**，每个词都用"字形 + 上下文 + 语法"三重确认：
   - 字形对不上但语法上只可能是某个词 → 采用该词，同时记下"字形存疑"。
   - 字形清楚但拼错了 → **转写成标准拼写**，在错误栏里如实写出学生的写法。
4. **语法核对**：格、性、数、动词变位、比较级、体。按句型逐句检查。
5. **批改痕迹**：红笔 ✗、勾、下划线、圈——说明它标在哪一句旁边、可能指什么问题；不确定就说不确定。
6. **输出格式**（见下）。

## 输出格式

```
## 识别结果
| # | 原文（标准拼写） | 中文翻译 |

## 错误 / 存疑
- 第 N 句：学生写作 **xxx** → 应为 **yyy**（原因）
- 第 N 句：某词字形不清，按语境读作 zzz

## 老师批改
- 红色 ✗ 位于第 N 句旁 → 可能指……
```

公式类手写：按人类书写习惯排版（分式上下排、上下标、√ 覆盖全式），不要写成一行 `a/b^2`。

## 俄语手写体字形要点（易混字母）

| 手写形状 | 实际字母 | 区分方法 |
|---|---|---|
| 像拉丁 *m* | **т** | 有时上方加横线；比 м 少一个起笔小勾 |
| 上方有横线的 *ш* | **т** | 有些人给 т 加横线以区别于 ш；ш 有时下方加横线 |
| 像拉丁 *u* | **и** | и 没有横线 |
| *u* 上加弧 | **й** | 注意不要漏读成 и |
| 像 *ʒ*（带下钩） | **з** | 和 э 区分：э 中间有横、开口朝左 |
| 像 *g* 或 *∂* | **д** | 带下伸笔画的是 д |
| 像拉丁 *n* | **п** | п 和 л、м 的区别在起笔：л、м 起笔有小勾 |
| 像 *r* 的下伸 | **р** | |
| *ч* 写得像 *r* / *4* | **ч** | 词首 Чем/Что/Чтобы 最常见 |
| 像 *e*、易写成 *c* | **е** | 圈没封口时容易读成 с |
| *ы* 拆开 | **ь + I** | 两部分距离近就是 ы |
| 大写形 **Я**、**Ь** 出现在词中 | 小写 я / ь | 学生常这样写，不算错 |
| ё 上的两点 | **ё** | 有点就写 ё（如 идёт） |

**连笔规则**：л、м、я 起笔都有一个"小钩"，连在前一个字母后面时容易被看成前一个字母的一部分——遇到多出来/少一个竖笔时优先考虑这一点。

## 常见学生错误（核对时重点看）

- 重复字母：уровнень（应 уровень）、ссосредоточиться
- 词尾：-ться / -тся 混用（不定式 -ться，第三人称 -тся）
- 比较级：дольше / долше，здоровее / здоровей，ярче / ярчее
- 复数第二格：овощей、фруктов、языков
- «Чем…, тем…» 中间必须有逗号

### 2026-11-26 «Чем…, тем…» 比较级句型 7 句
1. Чем громче играет музыка, тем труднее сосредоточиться.
2. Чем ближе экзамены, тем больше студенты занимаются.
3. Чем больше иностранных языков знает человек, тем легче ему найти работу.
4. Чем ярче светит солнце, тем лучше настроение.
5. Чем интереснее фильм, тем быстрее летит время.
6. Чем дольше идёт дождь, тем выше уровень воды в реке.
7. Чем больше овощей и фруктов в рационе, тем здоровее человек.

字形：此人 т 写成 *m* 形，ш 上加横线；з 为 *ʒ* 形；词尾 я 用大写 Я。
存疑：第 6 句 уровень 疑写成 уровнень，воды 结尾像 води；红色 ✗ 在第 6、7 句之间右侧。
